# EventEase — Shared Moments

A standalone Blazor WebAssembly event-management portfolio project by Digital Hope.

## Run locally
Install the .NET 10 SDK, open this directory, then run:

```sh
dotnet restore
dotnet run
```
Open the localhost URL printed in the terminal. The repository contains source code; a GitHub Pages deployment is not required by this assignment.

## Features
- Reusable EventCard: name, date and location; two-way editing; a separate draft prevents invalid edits or cancellation from changing the saved event.
- Event search and six-card pagination, with stable component keys and cached search results.
- Routes: `/`, `/events/{id}`, `/register/{id}`, `/attendance/{id}`, `/session`.
- Invalid addresses and unknown event IDs show helpful messages.
- Registration validates name and email, trims whitespace and blocks duplicate email registrations for the same event.
- Scoped EventStore retains registration details and attendance while navigating within the application.
- Attendance checkboxes support check-in and reversing check-in, with live totals.
- Responsive layout, semantic landmarks, labelled fields, keyboard focus styles and a skip link.

## Demonstration scope
All data is in browser memory and resets on reload. Session details are convenience state, not authentication. Editing and attendance management are intentionally available to all visitors in this educational demonstration; a production service would require authentication, authorization and persistent storage.

## Validation
The app compiled with zero warnings and errors. Store checks verified invalid input, missing events, whitespace trimming, duplicate registration, registration for another event, session continuity, attendance toggling and clearing saved details. Browser checks verified required-field errors, successful registration, attendance totals and session navigation.
